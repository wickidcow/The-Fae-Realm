# The Fae Realm

This repository hosts **The Fae Realm**, a Paper 26.2 / Java 25 fantasy world-generator project.

The active Paper development branch is `paper-26.2`. It creates a generator-driven floating fantasy world named **Fae Realm** (`fae_realm`) with deterministic terrain, five regional biome identities, vegetation, resources, structures, dungeon vaults, portal travel, and optional BetterStructures integration.

The Paper generator is not a pre-generated map and does not require a modded client. New chunks are generated from the realm seed as players explore.

The repository retains the original NeoForge source history from the project it was forked from for reference and licensing continuity. The Paper plugin does not bundle the original Aether project's all-rights-reserved assets.

See `README-PAPER.md` on the `paper-26.2` branch for the current generator feature set and configuration.
