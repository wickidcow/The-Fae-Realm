# The Fae Realm 0.4.0

The Fae Realm 0.4.0 is the first release with **Minecraft/Paper 26.3 as the primary target** while preserving compatibility with **Paper 1.21.11 and newer** on **Java 25**.

## Compatibility

- Primary target: Paper 26.3
- Compatibility floor: Paper 1.21.11
- Java: 25
- Plugin API floor: 1.21.11
- One JAR is used across the supported Paper range.

## Highlights

- Fae Realm generator revision v9 ("Living Islands")
- Floating continents and islands with terrain profiles
- Regional Fae biomes and resource generation
- Fae structures, landmarks, vaults, and dungeons
- Progression items and portal travel
- Custom glowstone/water Fae portal
- BetterStructures optional integration
- Dense Fae cow herds
- Chunky-safe concurrent BlockPopulator guard
- Existing generated chunks remain preserved when upgrading

## Verification

The release pipeline compiles against the Paper 1.21.11 API floor, builds against the Paper 26.3 primary API, verifies the packaged plugin classes and descriptor, and boots the exact release JAR twice on both Paper 1.21.11 and Paper 26.3.

The two-boot runtime checks verify Fae Realm creation, generator metadata, persistence across restart, command availability, world storage, normal shutdown, and the absence of linkage errors such as `NoSuchMethodError` and `NoClassDefFoundError`.

## Upgrade notes

Back up the server before updating as usual. Existing Fae Realm chunks are intentionally preserved; current generator behavior applies to newly generated chunks.
